# Code-, UI- und UX-Audit vom 22. November 2026

Geprüft wurde der GitHub-Zielbranch `main` bei `ddde566aee5775b90fcc4b9b0aec2f7ca9de2e8e` auf macOS 14.6.1 arm64 mit Node.js 22.16.0. Die Paketversion lautet 0.1.8. Der Release-Tag `v0.1.8` verweist auf den früheren Commit `d6bec6c`. Für den SVG-Vergleich wurden beide Revisionen ausgeführt. Das Audit und die unabhängige Wiederholung der Teilprüfungen erfolgten durch OpenAI Codex. [Audit #267](https://github.com/J-ARTS/de.sketchdraw.io/issues/267)

Zwölf Produktfehler sind am geprüften Stand nachvollziehbar. Sieben erhielten neue Tickets, vier waren bereits offen, ein Ticket wurde wieder geöffnet. Hinzu kommt ein Fehler in der lokalen Testinfrastruktur. Vorrang haben Vorgänge, bei denen Sketchdraw eine Änderung als gespeichert erscheinen lässt, fremden Zustand schon vor der Bestätigung ändert oder strukturierte Daten beim Import verliert.

## UX-Verbesserungen

1. **Exportverluste vor dem Speichern verständlich zeigen.** Bei der EC2-Karte kann die Vorschau konkret melden „1 AWS-Karte wird als Rechteck exportiert“. Eine Vorschau der erzeugten Darstellung bzw. des Mermaid-Quelltexts macht die Entscheidung überprüfbar. [Exportpanel](../../../src/renderer/design-system/organisms/InteropPanel.vue)
2. **Die Folienaktionen an einer sichtbaren Stelle bündeln.** „Umbenennen“ in das geplante Folienmenü aufnehmen und den Doppelklick als schnellen zweiten Zugang erhalten. Wer mit Tastatur arbeitet, kann denselben Menüpunkt benutzen. [#266](https://github.com/J-ARTS/de.sketchdraw.io/issues/266)
3. **Im Aufgabenboard leere und gefilterte Ergebnisse unterscheiden.** Aktuell erscheint in beiden Fällen „Keine Aufgaben“. Bei aktiver Suche zeigt „0 von 12 Aufgaben“ zusammen mit „Suche zurücksetzen“, dass die Karten weiterhin vorhanden sind. [Aufgabenboard](../../../src/renderer/design-system/organisms/TaskBoard.vue)

| Zusätzliche Audit-Proben | Produktiver Dokumentstore mit simulierter Desktop-Brücke und Zwischenablage, produktive Vue-Komponenten auf einem Testrenderer, Jira-Brücke mit kontrolliertem Abruf, Electron-Main-Handler im Ereignismodell sowie Produktionskonverter auf Release- und Hauptbranchstand.
